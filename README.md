# Voice Translation App

An Android application built with Java and XML layouts in Android Studio, designed to support voice input, language translation, and spoken output.

## Features

- Voice input using Android speech recognition
- Language selection for translation
- Translation of recognized speech
- Text-to-speech output in the selected language
- Android user interface built with XML layouts
- Error handling for supported speech and translation operations

## Technologies Used

- **Java** — application logic
- **XML** — Android layouts and UI resources
- **Android Studio** — development environment
- **Gradle** — build configuration and dependency management
- **Android speech recognition and text-to-speech APIs**
- **Translation library or service** — see the project source and Gradle dependencies for the specific implementation

## Project Structure

- `app/src/main/java/` — Java source files
- `app/src/main/res/layout/` — XML layout files
- `app/src/main/res/drawable/` — drawable resources, if present
- `app/src/main/AndroidManifest.xml` — application configuration and permissions
- `gradle/` — Gradle wrapper configuration

## Requirements

- Android Studio
- A compatible Android SDK
- The JDK version required by the project's Gradle configuration
- An Android device or emulator

Some voice and translation features may require microphone permission, an internet connection, or supported language services.

## Getting Started

1. Clone or download this repository.
2. Open the project root in Android Studio.
3. Allow Gradle to sync and download dependencies.
4. Run the app on a compatible emulator or Android device.
5. Grant microphone permission when requested if voice input requires it.

## Build

Use Android Studio's **Build → Make Project** option to check that the project compiles.
